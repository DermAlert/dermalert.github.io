Bem-vindo à documentação do DermAlert.

Use os menus acima para navegar pela documentação técnica, materiais de apoio e registros do projeto.

## Acesso local à landing

A homepage pública fica no app Vite em `docs/land`.

Para desenvolver a landing, rode:

```bash
cd docs/land
npm run dev
```

Depois acesse o endereço exibido pelo Vite, normalmente `http://127.0.0.1:5173/`.

Se você já gerou o build da landing, também pode abrir a versão estática servida pelo MkDocs em:

<a href="/land/dist/">Abrir landing gerada</a>
